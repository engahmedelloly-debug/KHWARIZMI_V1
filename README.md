# خوارزمي — KHWARIZMI V1

منصة ومجتمع لطلاب علوم الحاسب والبيانات، تساعد الطالب يفهم المجالات، يختار تخصصه، ويمشي في Roadmap واضحة بدل التشتت بين المصادر.

## V1 الحالية
- تخصصات ومسارات تعليمية.
- Roadmaps بمصادر عربية وإنجليزية.
- مقالات تقنية مع مصادر موثوقة.
- كويزات وتصحيح من السيرفر.
- حسابات مستخدمين حقيقية.
- XP ومستوى وStreak.
- حفظ تقدم الـRoadmap لكل حساب.
- Dashboard / Profile / Leaderboard متصلة بالـBackend.

## تشغيل الموقع + الـBackend
يتطلب Node.js 22+.

```bash
node server.js
```

ثم افتح `http://localhost:3000`.

لا تحتاج `npm install` لأن الـBackend الحالي لا يعتمد على packages خارجية؛ SQLite وcrypto وHTTP مستخدمة من Node نفسه.

للتفاصيل: راجع `BACKEND.md`.


## المعاينة على الموبايل / TrebEdit
- افتح `index.html` من مجلد المشروع لمعاينة الواجهة.
- عند فتح الصفحات مباشرة (`file://`) تستخدم المنصة بيانات محلية احتياطية؛ لذلك تظهر المقالات والتخصصات والكويزات والمصادر حتى بدون تشغيل السيرفر.
- تسجيل الدخول والتقدم في وضع المعاينة محليان على نفس المتصفح/الجهاز وليسا حسابات قاعدة البيانات الحقيقية.
- لاختبار الحسابات وحفظ التقدم على قاعدة البيانات، شغّل `node server.js` في بيئة Node.js ثم افتح الموقع من عنوان السيرفر مثل `http://localhost:3000`.
- عند تعذر API، يظل المحتوى العام ظاهرًا من البيانات المحلية؛ لا يعني ذلك أن عمليات الحفظ على قاعدة البيانات نجحت.


## قبل النشر العام
هذه نسخة مرشحة للاختبار وليست اعتمادًا نهائيًا للنشر العام. قبل فتح التسجيل للجميع: اضبط `NODE_ENV=production` و`JWT_SECRET` قويًا في إعدادات الاستضافة، واستخدم HTTPS وتخزينًا دائمًا لملف SQLite، واختبر التسجيل وتسجيل الدخول واستمرارية البيانات والنسخ الاحتياطي على الاستضافة المستهدفة. لا ترفع ملف قاعدة البيانات الحي أو أسرار البيئة إلى GitHub.


## تجهيز الاستضافة
- استخدم استضافة تشغّل Node.js 22 أو أحدث، وليس Static Hosting فقط.
- Build command: `npm install` (لا توجد dependencies خارجية حاليًا، لكنه مقبول)؛ Start command: `npm start`.
- اضبط متغيرات البيئة من لوحة الاستضافة: `NODE_ENV=production`، و`JWT_SECRET` عشوائي قوي بطول 32 حرفًا على الأقل، و`DB_FILE` لمسار داخل قرص دائم.
- لا تعتمد على قرص مؤقت أو على نسخة `kharazmi.sqlite` المحلية؛ يجب أن تكون قاعدة البيانات على Persistent Disk/Volume مع نسخ احتياطي.
- استخدم HTTPS، واختبر إنشاء حساب ثم تسجيل الخروج والدخول مرة أخرى، وحفظ تقدم Roadmap ونتيجة Quiz، ثم أعد تشغيل الخدمة وتأكد من استمرار البيانات.
- هذه نسخة Release Candidate لاختبار الاستضافة، وليست تصريحًا بأن كل اختبارات الإنتاج والخصوصية والامتثال اكتملت.
